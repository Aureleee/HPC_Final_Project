## HPC Final Project
This repository contains the code we developed for our **HPC final project**.  
The goal is to experiment with **parallel computing (MPI)**, **graph algorithms**, and some small **data processing utilities**.  
We try to keep the code simple and readable so anyone can run it locally without too much effort.

___

## Instructions
*Let's assume you know nothing about git or coding ig haha. Just follow these steps to begin :D*

Clone the repository somewhere on your machine:

```bash
git clone git@github.com:Aureleee/NLP_Supervised_Learning.git potato
````

Move inside the project folder:

```bash
cd potato
```

Then setup the environment:

```bash
bash setup.sh
```

This script installs everything required to run the project. Then execute
```bash
source .i_love_cats/bin/activate
```

→ You should now be able to run the code locally.
